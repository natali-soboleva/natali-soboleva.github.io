# CLAUDE.md — сайт тренера Натальи Соболевой

Одностраничный сайт-визитка (в стиле Taplink) для Натальи Соболевой, тренера тренажёрного зала
(фитнес-клуб SportFamily, Витебск, Беларусь). Сайт делается как **сюрприз**: заказчица —
её ученица и фотограф (фото с соревнований — её). Информацию от самой Натальи добавим позже.
Чек-лист запуска и передачи — в [HANDOFF.md](HANDOFF.md), инструкция для правки — в [README.md](README.md).

## Стек
- Astro + Tailwind CSS, статический сайт. Хостинг — Cloudflare Pages, код — GitHub.
- Админка — Pages CMS (pagescms.org), настройки в `.pages.yml`. Вход по email.
- Всё содержимое — в `content/site.json`. Тексты в компоненты не вписывать.
- Не добавлять библиотеки, сервисы, аналитику без согласования с владельцем.
- Шрифты — только OFL, файлы в `public/fonts/`: Cormorant (заголовки), Inter (текст),
  Marck Script (подписи от руки).

## Фото и видео
- Фото — `src/assets/photos/` (Astro сам делает WebP нужных размеров). Путь в site.json:
  `/src/assets/photos/имя.jpg`. Чёрно-белые — настройка `settings.blackWhitePhotos` (CSS-фильтр).
- Видео-урок — 5 частей в `public/video/lesson-N.mp4` + обложки `lesson-N.jpg`.
  Лимит Cloudflare Pages — 25 МБ на файл; части сжаты до ~23 МБ (540×960).
- Исходники (все 311 фото с wfolio, видео 2,6 ГБ) — `_source/`, в git не хранятся.

## Порядок работы
- Сначала план, потом код. Небольшие шаги, после каждого — `git commit`.
- `git push` — только по просьбе владельца.
- Перед завершением — `npm run build` без ошибок.
- Mobile-first. Цвета — только из `@theme` в `src/styles/global.css`.

## Команды
- `npm run dev` — сайт на компьютере (http://localhost:4321).
- `npm run build` — сборка в `dist/`.
