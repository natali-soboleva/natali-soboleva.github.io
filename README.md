# Сайт Натальи Соболевой

## Как поменять что-нибудь на сайте

1. Откройте **https://app.pagescms.org** и войдите по своей почте (придёт письмо со ссылкой).
2. Выберите сайт → раздел **«Сайт»**.
3. Поменяйте нужное:
   - **Первый экран** — имя, подпись, девиз, главное фото.
   - **Обо мне**, **Виды тренировок**, **Как проходят тренировки** — тексты и фото.
   - **Урок (видео)** — части урока. Каждый файл — не больше 25 МБ.
   - **Онлайн-занятия**, **Сертификаты** — включите галочку «Показывать блок», когда будет что показать.
   - **Контакты** — Instagram и где вы тренируете.
4. Нажмите **Save** (Сохранить). Через 1–2 минуты изменения появятся на сайте.

Фото лучше загружать вертикальные, хорошего качества (от 1200 px по короткой стороне).
Сайт сам уменьшит их, чтобы страница быстро открывалась.

Если что-то пошло не так — ничего не сломается навсегда: все прошлые версии сохраняются,
разработчик может вернуть любую.
